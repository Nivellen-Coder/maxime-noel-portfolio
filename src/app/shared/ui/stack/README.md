# Stack

## Description

Organise les éléments verticalement à l'aide de Flexbox.

## Quand l'utiliser ?

- Formulaires
- Cartes
- Panneaux
- Sections

## Quand ne pas l'utiliser ?

- Ligne horizontale → Inline
- Grille → Grid
- Largeur maximale → Container
