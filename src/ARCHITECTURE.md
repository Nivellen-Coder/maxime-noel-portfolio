# Nova Design System

> Modern Angular Design System built for the future.

Nova est une bibliothèque de composants Angular moderne conçue autour des principes suivants :

- Simplicité
- Performance
- Accessibilité
- Composition
- Design Tokens
- API cohérente
- Maintenabilité

Nova privilégie toujours les API natives d'Angular avant toute abstraction supplémentaire.
